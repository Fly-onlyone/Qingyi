# Qingyi Plugin Installation

## Quick Install (CLI)
Run from the Qingyi root directory:

### Windows:
scripts\install.bat

### Linux/macOS:
chmod +x scripts/install.sh && ./scripts/install.sh

## Manual Install (Claude Code Slash Commands)
/plugin marketplace remove qingyi
/plugin marketplace add ./
/plugin install qingyi@qingyi
/plugin install qingyi-code-review@qingyi
/plugin install qingyi-modernizer@qingyi

## Uninstall
### Windows:
scripts\uninstall.bat

### Manual:
/plugin uninstall qingyi
/plugin uninstall qingyi-code-review
/plugin uninstall qingyi-modernizer
/plugin marketplace remove qingyi
