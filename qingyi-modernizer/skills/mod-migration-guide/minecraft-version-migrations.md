# Minecraft Version Migrations

Breaking changes between Minecraft versions.

## 1.19 → 1.20

### Creative Tabs
- **Old**: `CreativeModeTab` enum
- **New**: `CreativeModeTab.builder()`

### Item Properties
- **Change**: Constructor changes for item properties

## 1.20 → 1.21

### Capabilities → Components (NeoForge)
- **Old**: Capabilities system
- **New**: Data Attachments

### Registry Changes
- **Change**: Some registry methods simplified

## 1.21 → Future

Monitor Forge/NeoForge documentation for upcoming changes.
