### 2.4 Migrate Network Packets

**Create new packet format**:
```java
public record EnergyPacket(int entityId, int energy) implements CustomPacketPayload {
    public static final Type<EnergyPacket> TYPE =
        new Type<>(new ResourceLocation(MODID, "energy"));

    public static final StreamCodec<FriendlyByteBuf, EnergyPacket> CODEC =
        StreamCodec.composite(
            ByteBufCodecs.INT, EnergyPacket::entityId,
            ByteBufCodecs.INT, EnergyPacket::energy,
            EnergyPacket::new
        );

    @Override
    public Type<? extends CustomPacketPayload> type() {
        return TYPE;
    }
}
```

## Backward Compatibility

### Registry Name Preservation
**CRITICAL**: DO NOT change registry names! Items will become AIR in existing worlds.

If you must change names, add remapping:
```java
@SubscribeEvent
public static void onMissingMappings(MissingMappingsEvent event) {
    event.getMappings(Registries.ITEM, MODID).forEach(mapping -> {
        if (mapping.getKey().getPath().equals("old_name")) {
            mapping.remap(ModItems.NEW_NAME.get());
        }
    });
}
```

### Capability Data Migration
Old capability data is stored in entity NBT under `ForgeCaps`. Migration code:
```java
public static void migrateCapabilityData(Entity entity, CompoundTag entityNbt) {
    if (entityNbt.contains("ForgeCaps")) {
        CompoundTag forgeCaps = entityNbt.getCompound("ForgeCaps");
        CompoundTag oldEnergy = forgeCaps.getCompound("examplemod:energy");
        if (!oldEnergy.isEmpty()) {
            EnergyData newData = entity.getData(ModAttachments.ENERGY);
            newData.setEnergy(oldEnergy.getInt("energy"));
        }
    }
}
```
